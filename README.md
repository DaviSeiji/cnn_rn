# Projeto 5 — CNN

Projeto da UC de Redes Neurais, desenvolvido em **Jupyter Notebook** utilizando **PyTorch**.

## Descrição

Implementar uma Rede Neural Convolucional (CNN) para classificar imagens do dataset **CIFAR-10**, utilizando suas 10 classes.

O projeto deve:

- Avaliar **mais de 5 topologias** de CNN e diferentes parâmetros.
- Calcular a **matriz de confusão** dos dois melhores modelos.
- Comparar os dois melhores modelos usando o **teste de McNemar**.
- Treinar uma **MLP** e compará-la com a CNN em termos de **acurácia e número de parâmetros**.

Dataset: https://www.cs.toronto.edu/~kriz/cifar.html
